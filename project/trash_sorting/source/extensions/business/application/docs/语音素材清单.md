# 板载语音素材清单

语音由 `application/tools/make_voice.ps1` 使用本机 `Microsoft Huihui Desktop` 离线生成，输出格式统一为 48 kHz、16-bit、单声道 PCM WAV。文本中的“哎呀，答错了”是对“哎呀打错了”的语义规范化。

| 文件 | 播放文案 | 用途 |
| --- | --- | --- |
| `PROMPT.WAV` | 请选择垃圾桶。 | 检测到目标后提示选择 |
| `CORRECT.WAV` | 恭喜你，答对了！ | 答题正确 |
| `WRONG.WAV` | 哎呀，答错了。 | 答题错误 |
| `TIMEOUT.WAV` | 选择超时，请移走垃圾后重试。 | 等待答题超时 |

生成后的 WAV 会写入 `application/assets/audio/`，上板时复制到 FAT32 SD 卡根目录。`VOICE_MANIFEST.json` 保存文案和格式元数据；该 JSON 不会被音频播放固件加载。
