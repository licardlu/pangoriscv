# 积分与音频状态界面

> 这是上一轮深色界面的记录。当前已改为顶部简洁状态区、下方全宽视频，积分与音频面板已移除，详见《白色分屏与提示语音.md》。snapshot 位定义继续沿用，旧坐标和旧截图不作为当前验收依据。

`rtl/ui_rgb.sv` 的独立应用显示保留右上角积分数字，右下旧的积分扣费选曲列表改成答题音频奖励面板。当前选用 `assets/audio/MUSIC0.WAV`，面板名 `MORNING PATH`（晨光小径）。该 WAV 为项目脚本合成的原创短旋律。

面板显示 `EXTERNAL SPEAKER`、`I2S 48KHZ PCM16`，对应外接 I²S 功放/音箱。当前版本不在 HDMI 中复用音乐兑换按钮，不在显示层扣分。

## 独立显示快照

| 位段 | 含义 |
| --- | --- |
| `snapshot[63:32]` | 当前本机积分，无账号绑定条件；32 位完整数值，最多 10 位十进制数字 |
| `snapshot[123]` | 音乐已经实际启动，显示 `PLAYING`；等价于 `R_UI_FLAGS` bit 27 |
| `snapshot[124]` | 默认 `MUSIC0.WAV` 已加载，显示 `READY`；等价于 `R_UI_FLAGS` bit 28 |

两位都为零时显示 `ASSET MISSING`。语音提示播放不应置音乐播放位。播放位由音频驱动的实际启动事件更新；文件就绪位由 WAV 校验/加载结果更新，不用界面动画推断播放成功。

上述 bit 27/28 仅适用于非 `BUSINESS` 的本机应用界面。旧 `BUSINESS` 网关模式有自己的位定义，新面板不会在该模式下绘制。界面本身不定义积分加分规则、账户或掉电存储；这些由固件状态机负责。
