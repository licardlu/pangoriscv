# 四路舵机中继说明（FPGA 出 PWM 指令，STM32 重新生成动作）

日期：2026-11-04。对应工程：`D:/FPGA_Project/舵机测试/test/MDK-ARM/test.uvprojx`（STM32F103C8T6，HAL 库，Keil MDK）。

## 1. 先纠正一个前提

原来的想法是「FPGA 有 PWM 就是 1、没有就是 0」。这条判据在现在的 RTL 上不成立。

`extensions/business/application/rtl/servo_pwm4.sv` 第 59 行：

```systemverilog
pwm[i] <= (period_count < ((open_state[i] ^ REVERSED_MASK[i]) ? PULSE_90 : PULSE_0));
```

每个 20 ms 周期都会产生一次脉冲，**四路空闲时也在发 0.5 ms 的闭盖脉冲**，不存在「没有波形」的状态。如果按「有波形 = 开」来判，上电后四个桶会全部判成打开。

能用的信息只有**脉宽本身**：

| FPGA 输出 | 含义（正常路） | 含义（反装路，掩码位=1） |
| --- | --- | --- |
| 1.5 ms 高 | 该桶打开 | 该桶关闭 |
| 0.5 ms 高 | 该桶关闭 | 该桶打开 |
| 完全无波形 | 当作关闭 | 当作关闭 |

所以 STM32 是「量脉宽 → 判该不该开 → 自己重发一套干净的动作」，不是「有没有信号」。

## 2. 两个方向掩码

一位对应一路：**bit0 蓝 / bit1 灰 / bit2 红 / bit3 绿**。

```c
#define SERVO_IN_MASK   0x0U   /* FPGA 哪几路是"窄=开"，要和 RTL 的 SERVO_REVERSED_MASK 一致 */
#define SERVO_OUT_MASK  0xDU   /* 哪几路舵机是反装的，输出脉宽要反过来：蓝+红+绿 */
```

- **IN**：`build_servo_repair_20261103` 的顶层实例化没有接 `SERVO_REVERSED_MASK`，取默认 `4'b0000`，所以那份位流配 `0x0`。**但本包唯一随附的位流是 v3（`prebuilt/full_v3_27mhz/yolo_camera_top.sbit`），它的顶层是 `4'b0101`，配它必须写 `0x5`。** 拿 `0x0` 去配 v3，蓝、绿两路的开关判定会整体反过来。改之前先确认手上是哪份位流：

  ```powershell
  Select-String -Path ..\..\prebuilt\full_v3_27mhz\052_yolo_camera_top_camera_servo.v -Pattern 'SERVO_REVERSED_MASK'
  # .SERVO_REVERSED_MASK(4'b0101)  -> SERVO_IN_MASK 写 0x5
  ```

- **OUT**：机械上装反的那几路。RTL 里原来用 `4'b0101` 做补偿，现场实测**绿桶（厨余）也是反的**，所以取 `0xD` = 蓝 + 红 + 绿。

2026-11-04 现场记录：蓝桶上电关得很好，绿桶（厨余）上电直接弹开、答题时反而关上 —— 就是绿桶这一位漏了，`0x5` 改成 `0xD`。灰桶当时没报异常，所以保持 0；如果之后发现灰桶也是上电就开，把 bit1 加上变成 `0xF`。

两路反装不是故障，是安装方向问题：舵机转轴反着装，机械上的「关」对应 90° 而不是 0°。以前直接在 RTL 里对调脉宽来补，现在改成在 STM32 里补，RTL 那边反而干净了。

## 3. 接线表

### 3.1 FPGA → STM32（4 根信号 + 1 根地）

| 桶 | FPGA 球号 | 标准 FMC 子卡 J3 | STM32 引脚 | Blue Pill 丝印 |
| --- | --- | --- | --- | --- |
| 蓝（通道 0） | U16 | J3.27 | **PB12** | B12 |
| 灰（通道 1） | U15 | J3.28 | **PB13** | B13 |
| 红（通道 2） | AC26 | J3.29 | **PB14** | B14 |
| 绿（通道 3） | AB26 | J3.30 | **PB15** | B15 |
| 地 | GND | — | **GND** | G |

你现在那块无标号转接板的针序和标准子卡 J3 不是一回事，**按颜色对应的四根杜邦线接**，别照 J3 的针号数。

### 3.2 STM32 → 舵机（这四根才是给舵机的 PWM）

| 桶 | STM32 引脚 | 丝印 | 定时器通道 |
| --- | --- | --- | --- |
| 蓝 | **PA0** | A0 | TIM2_CH1 |
| 灰 | **PA1** | A1 | TIM2_CH2 |
| 红 | **PA2** | A2 | TIM2_CH3 |
| 绿 | **PA3** | A3 | TIM2_CH4 |

PA0..PA3 在 Blue Pill 上是连着的四个针，四根信号线可以插成一排。原来单路测试用的就是 PA0。

### 3.3 电源

- 舵机电源外接稳压 **5 V，建议 3 A 以上**，不要从 STM32 的 3.3 V 取。
- **FPGA 地、STM32 地、舵机电源地三者共地**，上次乱跳大概率就是这里。
- FPGA 输出是 LVCMOS33 ≈ 3.3 V，STM32 直接读，不用电平转换。

## 4. 动作时序

对外的机械动作，四路完全一样：

```
上电/待机        收到"开"指令                保持             自动关闭
  关到位  ──1 秒线性──►  开到位  ──── 5 秒 ────►  开到位  ──1 秒线性──►  关到位
```

- **上电第一件事就是关到位**，不会再出现"一上电先弹开"。
- 0.5 ms / 1.5 ms 之间每 20 ms 走 20 µs，1 秒走完。
- 90° 保持 5 秒（`SERVO_HOLD_MS`）。
- 周期全程 20 ms（50 Hz）不变，只改高电平宽度。
- 只在"关→开"那一下触发一次；要再开必须等指令回到"关"持续 100 ms 以上。

**反装的两路**：物理动作一样是关→开→关，只是输出给舵机的脉宽对调了——待机时发 1.5 ms（对它来说才是关），打开时发 0.5 ms。拿示波器看会觉得"反着"，但机械上是对的。

## 5. 代码在哪

全在 `Core/Src/main.c` 的 `USER CODE` 段，CubeMX 重新生成不会冲掉；没有往 Keil 工程加新文件，直接编译原来的 `test.uvprojx`。

| 位置 | 作用 |
| --- | --- |
| `USER CODE PD` | 脉宽/步进/5 秒/两个掩码/判定门限，全在这里 |
| `TIM3_IRQHandler` | 100 µs 采一次 PB12..PB15，20 ms 一窗口数高电平点数 |
| `Servo_Init` | 四路 PWM 输出、四路输入下拉、TIM2/TIM3 初始化，初始化即关到位 |
| `Servo_Task` | 每 20 ms：点数换算成指令 → 消抖 → 四态状态机 → 写 CCR |

判定用三档，中间留了死区，不会在门限附近抖：

```c
#define IN_NO_SIG_CNT     2U    /* <=2 点：没波形，当关 */
#define IN_NARROW_CNT     8U    /* <=8 点：0.5ms 窄脉冲 */
#define IN_WIDE_CNT      12U    /* >=12 点：1.5ms 宽脉冲 */
```

0.5 ms 实际落在 5~6 个点、1.5 ms 落在 15~16 个点，两边都留了 3~4 个点的余量。

## 6. 怎么校准那两路反装的

1. 把 `SERVO_SELFTEST` 改成 `1`，重新编译下载（这时不用接 FPGA）。
2. 四路会轮流各开 10 秒，看四只舵机的方向。
3. 哪一路的动作是反的（该关的时候开到 90°），就把 `SERVO_OUT_MASK` 里对应的位翻一下：
   - 蓝反 → `0x1`，灰反 → `0x2`，红反 → `0x4`，绿反 → `0x8`，几路反就按位或起来。
4. 改回 `SERVO_SELFTEST 0`，重新编译。

接上 FPGA 之后如果哪一路"空闲就自己开、该开的时候反而关"，那是 **IN** 位填反了，不是 OUT。两种情况的区分办法：

- **上电瞬间就弹开**（没有过程）→ OUT 位反了，STM32 在老老实实发 0.5 ms，是舵机装反了。
- **上电后慢慢转开，约 1 秒** → IN 位反了，STM32 把 1.5 ms 认成了"开"，正在走斜坡。

## 7. 上板步骤

1. Keil 打开 `MDK-ARM/test.uvprojx`，编译（0 error）后下载。
2. 按第 6 节做一次方向校准。
3. 接 FPGA 四根信号线 + 一根地，**断开原来 FPGA 直连舵机的那四根**。
4. 上电，看四个桶是不是都乖乖关着。
5. 答题，对应桶的舵机慢开到 90°、停 5 秒、慢回关位。
6. 顺手量一下 FPGA 四个输出脚的高电平，应该是 3.3 V 左右。

## 8. 常见毛病

| 现象 | 先查什么 |
| --- | --- |
| 舵机完全不动，手能转动 | 舵机 5 V 没接 / 没共地 / 信号线插错 |
| 上电就有一只弹开 | `SERVO_OUT_MASK` 那一位填反了（第 6 节） |
| 上电后某路慢慢转开 | `SERVO_IN_MASK` 那一位填反了 |
| 四个桶同时乱开 | 四根信号线接错位；或 PB12..15 被外部拉高 |
| 开到 90° 一直嗡嗡响发烫 | 机械限位到了，把 `SERVO_PULSE_90DEG_US` 往下调（1400、1300 试） |
| 转动一顿一顿 | 舵机电源电流不够，或地线太细 |
| 答对一次之后再也不开 | 指令没回到"关"（`SERVO_REARM_MS` 要求先看到 100 ms 的关） |

## 9. FPGA 那边以后怎么配合

现在这套不要求改 RTL，拿板上现有位流就能跑。真要改，最省事的是把 `SERVO_REVERSED_MASK` 统一成 `4'b0000`，把方向补偿全部交给 STM32（`SERVO_IN_MASK` 也跟着改 0），RTL 就只剩一个纯粹的「这个桶该开」逻辑，布线压力更小。
