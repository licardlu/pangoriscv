# 双目近距离门控准备

用户确认：两个摄像头固定并排、朝向同一区域，中心间距约30毫米。TF/掉电自启暂缓，当前006实验版留给用户现场测试。本阶段只在电脑上核对与开发，不下载、不打开串口、不更新TF/Flash。

## 已核对的数据通路

冻结入口 `project/trash_sorting/candidates/overnight_020/frozen_20261116/yolo/portable/052_yolo_camera_top.v` 中，两路OV5640分别初始化并转换DVP数据，但320行的 `sel_cmos1=1'b1` 固定选第一路。快照时钟也固定由第一路产生。两路活动计数不能证明帧配对或曝光同步，当前版本尚无双目测距。

`048_camera_snapshot.v` 已有320×180×16位不可变快照，占115200字节。当前整机DRM占用155/155，不能直接再复制一份帧RAM，也不能把两个独立像素时钟作普通组合选择。接入第二路前需先确定采集、CDC和DDR带宽预算，再按模块合同补齐RTL设计字段及预算；本阶段没有新增RTL模块或FPGA资源。

## 已实现的电脑工具

入口 `project/trash_sorting/tools/stereo_offline.py`，使用现有 `build/trash_train_env/Scripts/python.exe` 的OpenCV。输出目录必须不存在，避免覆盖证据。

标定：读取相同分辨率的左右图片清单；使用实际打印棋盘的内角点数量和实测方格边长（毫米），至少12组有效且姿态不同的图；估计两路内参、畸变、相对旋转和平移并生成校正矩阵。检查重投影RMS≤1像素、校正后垂直误差p95≤1像素、基线与实测30毫米偏差≤20%、左右顺序和水平排列。拒绝重复图片和非有限数值。12组计数与误差阈值只是初筛，仍须人工检查姿态覆盖与独立实测误差。

距离诊断：先按标定参数校正左右图，用SGBM和反向匹配一致性、纹理、有效校正区域过滤无效像素，再对指定的物品ROI统计深度p10/中位数/p90。有效像素少于100或低于25%、ROI距离分布过宽时返回UNKNOWN，禁止把失败当成“远处背景”。20厘米诊断以p90≤200毫米为保守判据，尚未接入问答或待机状态机，也不构成实际误差保证。

运动场景需要真实曝光中心时间戳，来自同一个时钟；文件修改时间和USB到达时间不可替代。工具要求清单声明 `timestamp_source=exposure_common_clock` 并提供两路毫秒时间；曝光偏差超过5毫秒返回UNKNOWN。此阈值只是拒绝条件，不代表5毫秒内已足够同步；真实手部运动仍需验证。标定NPZ的SHA与质量报告绑定，禁止用另一份参数套用本报告。

清单结构如下，路径相对清单文件；标定静态棋盘可不带时间戳，距离诊断必须带：

```json
{
  "timestamp_source": "exposure_common_clock",
  "pairs": [
    {"left": "left/0001.png", "right": "right/0001.png",
     "left_timestamp_ms": 1000.0, "right_timestamp_ms": 1000.5}
  ]
}
```

使用示例（9×6为示例内角点数量，7毫米仅为示例，不可直接当实物参数）：

```powershell
& build/trash_train_env/Scripts/python.exe project/trash_sorting/tools/stereo_offline.py calibrate --manifest <配对清单.json> --board 9 6 --square-mm 7 --baseline-mm 30 --output <新的标定目录>
& build/trash_train_env/Scripts/python.exe project/trash_sorting/tools/stereo_offline.py measure --manifest <带曝光时间戳的配对清单.json> --calibration <标定目录/calibration.npz> --roi 140 25 90 120 --max-disparity 64 --output <新的距离诊断目录>
```

ROI坐标基于校正后的左图，不可直接套用未校正YOLO框。默认搜索128像素；可按分辨率设置16的倍数，但必须小于图像宽度。搜索范围不足时应返回未知，而不是声称更近处不存在物品。

## 接下来的实物步骤

1. 先结束本轮时序构建、核对最终STA，保持当前板上程序供用户测试。
2. 为左右采集设计独立时钟域握手及曝光/帧时间标识。评估复用现有快照分时导出静态棋盘的诊断模式；它仅能标定静态场景，不能用作动态距离门控。动态方案需DDR配对缓存或有资源依据的降采样存储；避免耗尽的DRM继续增加。
3. 实际采集棋盘覆盖画面中部、四角、倾斜和10～30厘米距离；校验左右顺序及棋盘角点方向，标定质量合格后冻结参数。
4. 用尺子实测10、15、18、20、22、25、30厘米，在静止、手持、纹理少/反光/遮挡条件下验证误差、UNKNOWN比例及错误触发。没有这些证据前不启用自动距离门控，现有单击开始/停止识别继续可用。
5. 距离门控与手部/垃圾检测联合：先确认有效近物，再确认垃圾主体；空手不能因距离近直接触发题目。未知距离不能立即当背景，需要防抖和保持状态，平滑切换动画。

目前没有实拍配对图和标定文件；电脑几何测试通过也不代表双目采集、物体距离或屏幕效果已验收。
