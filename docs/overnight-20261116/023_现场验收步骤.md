## 真实CoreMark

KEY1在跑分页启动5000次官方CoreMark。CPU主循环暂停推理、媒体服务和UART处理，硬件显示和活动条继续运行；结束恢复先前媒体暂停状态。这不等于关闭所有FPGA外设，也不宣称与独立CPU空载分数完全相同。

必须留存原始64位cycles、iterations=5000、cpu_hz=54000000及五CRC：`e9f5/e714/1fd7/8e3a/bd59`。cycles至少540000000才满足10秒。分数按`5000 × 1e6 / cycles`计算CoreMark/MHz；界面显示其三位小数截断值。CRC失败或不足10秒时隐藏有效分数。重复运行保留每次原始周期，不制造5.2附近的随机成绩。

## 识别

固定相机、照明和物品位置，逐项记录成功/错类/漏检/误触发及首次提问延迟；不要将开发集图片重放当作独立现场测试。

配套32条待测用例和空白测量字段见 `023_现场识别记录模板.json`；计时、计分、解除重复门控及失败样本隔离方法见 `023_现场样本采集与计分.md`。它们尚未执行，不代表现场成绩。

| 场景 | 待验收行为 |
| --- | --- |
| 电池：横握、竖握、手遮挡一端、只露中段 | 同类且IoU一致的两次推理后提问，观察漏检及局部框 |
| 玻璃罐：透明、反光、不同背景、手握罐体 | 核对回收类别和主体定位；记录反光失败条件 |

| 无手的空场景及边缘背景小物 | 不应触发答题；现有软件val仍有8/136误选，尚未解决 |

两帧确认增加一轮实际推理等待，必须记录延迟。当前无可靠20cm自动模式，使用单击KEY0启动/停止；自动距离切换需真实标定、同步、10/15/20/25cm误差测试和完整双目路径内存/栈验收后另行开启。
