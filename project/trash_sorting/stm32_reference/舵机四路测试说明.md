# STM32F103 单路舵机测试

> 本文是早期单路测试的存档，代码已被四路中继版替换。四路接线与动作说明见同目录 `四路舵机中继说明.md`。

本轮只测试一只舵机，使用 STM32F103C8T6 的 TIM2_CH1，从 PA0 输出控制信号。PWM 周期为 20 ms（50 Hz），高电平脉宽单位为微秒。

## 接线

| 舵机导线 | 连接位置 |
| --- | --- |
| PWM 信号线（黄/橙/白） | STM32 **PA0** |
| 正极线（红） | 外接稳压 **5 V 正极** |
| 地线（棕/黑） | 外接电源 GND |

PWM 是信号线，不是电源线。把外接电源 GND 同时接到 STM32 的 **GND**，两边必须共地。不要从 STM32 的 3.3 V 引脚给舵机供电。不同舵机线色可能不同，接线前核对舵机说明。

## 测试动作

程序在 PA0 持续输出 20 ms 周期（50 Hz）的 PWM，并把高电平宽度直接切换为 0.5 ms（约 0°）和 1.5 ms（约 90°）；每个目标停留 5 秒后切换。

先卸下舵盘上的连杆或负载再测试，不要通电时用手强行掰舵机。不同型号的端点角度可能不同；若舵机在 0.5 ms 或 1.5 ms 端持续嗡鸣、发热或被机械限位卡住，应立即断电。连续旋转舵机不能按普通位置舵机控制到固定角度。

在 CubeMX 打开 `test.ioc` 后，芯片引脚图中的 **PA0** 应显示为 **TIM2_CH1**，它就是这只舵机的 PWM 信号输出脚。然后在 Keil 中打开 `MDK-ARM/test.uvprojx`，编译并下载即可测试。STM32F103C8T6 默认映射无需重映射。
