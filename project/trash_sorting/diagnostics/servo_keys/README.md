# 四按键 / 四舵机独立测试

本版仅测试 FPGA 直接控制四只舵机，不需要摄像头、模型、HDMI、语音或 STM32。

| 板载按键 | 按键信号 / FPGA 球位 | 垃圾桶 | 舵机信号球位 | 标准子卡信号脚 |
| --- | --- | --- | --- | --- |
| 按键 1 | key_n[0] / C23 | 绿：厨余 | U16 | J3.27 |
| 按键 2 | key_n[1] / B22 | 红：有害 | U15 | J3.28 |
| 按键 3 | key_n[2] / A22 | 灰：其他 | AC26 | J3.29 |
| 按键 4 | key_n[3] / B20 | 蓝：可回收 | AB26 | J3.30 |

上电配置完成后四路默认关盖（1500 us 脉宽）。用户已经实测旧版四路500 us均为打开、1500 us均为关闭，当前使用方向掩码1111。轻按某个键超过20 ms，对应桶约1秒打开到位（500 us），**从开到位开始停留5秒**，再约1秒关回1500 us。长按只执行一轮；下一次测试松开再按。未按的通道保持关闭。用户要求的0°关闭/90°打开表示桶盖位置，不能直接用PWM名义轴角度代替实物盖子方向。

舵机信号从 FPGA 按表直接接入，绕过 STM32；舵机继续由原独立电源供电，电源负极、舵机 GND、FPGA GND 共地。J3 编号来自标准子卡；若用无编号转接板，以实际连通关系核对，球位不是排针序号。

交付路径：`bitstream/servo_key_test_top.sbit`；SHA256及下载状态以 `evidence/records/optimization/servo-keys-20261111-003/acceptance.json` 为准。旧SHA256 `4d48df1a…`对应mask0000，用户确认该版四路开关方向错误，不能继续作为交付版。纯RTL诊断没有CPU和程序镜像。

验证：四路启动必须输出1500 us，逐帧核对50步渐变至500 us、保持250帧、50步返回1500 us；其他通道保持关闭，长按不重触发。另跑完整应用16种答题/按键组合。27 MHz最终快慢角setup/hold均无失败端点（慢角+32.120/+0.223 ns，快角+33.954/+0.156 ns）；映射493 LUT、225 FF、0 LUTRAM。

当前实现/仿真证据：仓库 `evidence/records/optimization/servo-keys-20261111-003/`；最终成功JTAG下载及用户四路验收：`evidence/records/servo-keys-20261111-program-006/`。SRAM 下载掉电失效，需要重新下载。
