# 续训及上板结果

新增865张逐图复核标注，其中685张进入训练；最终4444 train/1929 val/1634 test，另77张新增验证。已完成多阶段续训，冻结stage4作为本次实际上板模型。

同部署量化算子与真实C后处理的软件验证：主体选中1452/1793（旧1398/1793）；无垃圾误选11/136（旧26/136）；新增77验证主体55（旧51）。这是软件数据集评估，不是板上实拍准确率。

有改善也有退步：纸团54/146（旧47/146），电池50/60（旧53/60），塑料片19/28（旧23/28），泡沫仅3/12。原test一次最终对照：浮点mAP50约0.81997（旧0.81876），C主体1424/1613（旧1412/1613），无垃圾误选同为1/21。不能声称所有类别都变好。

本次实际板测：新模型DDR CRC、四组硬件推理数值兼容、摄像头输入CRC、3次相机探针、真实相机推理、自主识别启动均通过。相机探针均值1.757秒，完整交互还包含语音/答题/舵机等待。实际自主相机仍有低置信背景候选；采用按键启停方案，不能给出可靠20厘米测距或背景零误检结论。

硬件是功能实验版：唯一Slow hold -0.012ns/1端点，尚未时序闭合。参见README与evidence，不把软件效果或四组数值样例冒称真实场景板上准确率。
