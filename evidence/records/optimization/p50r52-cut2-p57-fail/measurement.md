## 最差路径（连续 3 条同形）

```
rr_rs1[4] (net 1.051, fanout 39)
  -> u_regs 读 mux (N199) -> alu_a
  -> u_alu 4 级 -> alu_y
  -> mem_addr_h -> mem_from_h (net 0.861, fanout 126)
  -> lsu/store_q -> ... -> data_cache/data_mem_b1_*/ram64x1d/WE
Slack -0.991 / -0.941 / -0.891
```

**要点：这条路径的尾巴正是切⑥ 要解决的那一段**（store 命中在 accept 拍写阵列，写使能
由 `mem_from_h → LSU → w_strb` 组合决定）。⑥ 功能全对但 PDS 综合吃不下（lesson 90），
所以这一刀现在卡在工具链上，不是卡在想法上。

## 与交付版的关系（必须一起看）

| 网表 | 约束 | 摆放 | 布线后 | 结论 |
|---|---|---|---|---|
| `p48r50e`（交付，无 ②/无 P57）| 50 MHz | +1.683 | **19.355** | WNS **+0.645** ✓ |
| `p50r55`（②） | 55 MHz | +1.256 | 19.776 | −1.595 ✗ |
| `p50r52`（②+P57） | 52 MHz | +1.903 | 20.222 | −0.991 ✗ |

同族网表在 52/55 MHz 上布出来的绝对值（19.8~20.2 ns）**比交付版 50 MHz 的 19.355 ns 更差**，
尽管它面积更小、拍数更少。⇒ 这就是 lesson 9/85 的"布线抽签"：
**27% 利用率下，约 ±1 ns 的结果由摆放/布线抽签决定，而 5.2 分的 CPI 预算不允许用
"多切一级"去绕过它。**
