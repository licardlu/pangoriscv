# 023现场样本采集与计分

此表供获准实现、上板后使用；当前没有现场成绩，也没有执行串口或板卡操作。配套 `023_现场识别记录模板.json` 含32条待测用例，全部 `completed=false`，实际测量项为空。先复制模板到本次独立证据目录，填写后不覆盖原模板。

## 开始前

1. 核验实际板上版本、位流/固件/模型SHA；填写 `actual_*`，核验完成后才置 `identity_verified=true`。模板预填的023期望身份不能证明板上是023，旧022不能混入023结果。
2. 使用现有1280×720显示和单击KEY0手动识别。双目自动距离门控保持关闭；如记录距离，用尺量并填写实测值，不从框大小推算。
3. 固定相机位置与照明，登记拍摄会话、背景场景ID、物品实物ID。玻璃建议使用两个不同罐体、电池使用两个不同实物；缺少时如实填写同一ID。平整/杂乱两种背景分别登记，不把姿态变化称为独立场景。
4. 每条用例开始前移走前一件物品，等前一轮舵机完整闭合，并确认没有待回答题。识别重提需要连续两次成功无目标推理；不要靠切页假定已重置。若无法确认已解除重复门控，标记 `inconclusive`，不要算漏检。

## 用例与记录

| 分组 | 用例 | 每条计划观察 |
| --- | ---: | --- |
| 电池 | 横握、竖握、遮挡一端、仅露中段，各两种背景，共8条 | 最长30秒，记录首次提问延迟和类别 |
| 玻璃 | 正面透明、侧面反光、手握罐身、局部遮挡，各两种背景，共8条 | 同上 |
| 空手 | 掌心、手背、握拳、手指局部，各两种背景，共8条 | 完整30秒，记录实际提问次数 |
| 空背景 | 静态无人、手移出后、光照变化、画面边缘纹理，各两种背景，共8条 | 完整30秒，记录实际提问次数 |

纯观察共最多16分钟，加上移物、回答、舵机关盖和记录约需25～35分钟。实际耗时以记录为准。开始后不调整模型、阈值、光照或相机位置；需要改变条件时另开会话。

正样本以物品稳定进入识别画面为计时起点，以第一次开始提问为终点；用录像时间戳或计时器测量。第一次提问后记录当前类别/桶，再作答，不用答题后语音倒推首次预测。电池期望模型类2/有害、桶码2/红色；玻璃期望模型类1/可回收、桶码4/蓝色。这些类别号只适用于匹配的四桶模型。

一条正样本 `outcome` 只能填 `correct`、`wrong_class`、`miss` 或 `inconclusive`；30秒内没有提问才是本观察窗口内的 `miss`。观察中断、识别未开启、旧题未释放、版本未核实或证据不足使用 `inconclusive`，不当作正确/漏检。无提问时延迟填空，不填0；其他观测字段按实际记录。

空手/空背景 `outcome` 使用 `no_trigger`、`false_trigger` 或 `inconclusive`。记录完整实际观察时长及提问次数；一次误触发也算该用例误触发，提问被重复门控抑制不代表每帧没有误检。空场景应没有真实垃圾实物；若背景中实际有电池、罐体等，单独记录其位置和业务上是否希望忽略，不能当作“无垃圾”负标签。

## 计分

- 先报告32条计划中实际完成、无结论、未执行各多少条。版本身份未核实的会话不出023汇总。
- 对电池/玻璃分别计 `correct / (correct + wrong_class + miss)`，同时给出三个原始计数。只统计有结论且完成的用例。
- 空手/空背景分别报告 `false_trigger / (false_trigger + no_trigger)` 的用例比例、实际观察总秒数、实际提问总次数。不要把它叫逐帧误检率。
- 首次提问延迟只在实际提问且有时间记录的样本中汇总，并列出样本数及未提问数量；不把miss记为0秒或从延迟分母中隐去。
- 这32条是小规模现场开发诊断，重复实物/场景彼此相关。报告原始计数，不承诺推广到其他环境，也不与开发集1455/1793及8/136直接拼接。

## 留存失败样本

每个失败保留原始照片/录像、用例ID、物品身份、背景、光照、握法、当前错误类别和观测时间。不要只保留绘制了检测框的截图，也不要只挑成功帧。保护原始文件，标注另存。

新现场照片先放入独立 `field_review` 会话。复核可见的全部真实垃圾和手框后，再按拍摄会话/实物/近邻分组决定后续train与新的开发验证划分。同一视频相邻帧和同一实物连拍不得分散到不同split；不要只标手持物而漏掉确实可见的背景电池，更不要以空手来源名自动清空标签。

一旦用这批现场图定位错误、改阈值或训练，它就属于开发数据，不能再称最终独立测试。原来封存的最终test仍不用于选权重或阈值。新增训练方案须独立控制对照、固定train-only校准，并通过浮点及实际Q15选择策略门禁后才考虑部署；本模板不自动触发训练或上板。
