# 板载语音素材清单

## 023当前使用的ROM语音

当前HDMI人声使用 `assets/audio_rom/voice_rom_manifest.json` 对应的14段 `zh-CN-XiaoxiaoNeural` 语音。采用12kHz单声道IMA ADPCM，48kHz输出时每个样本保持4次，tempo=1.2；共116500字节、57个既有bank。量化相对参考PCM的最低SNR约20.92dB不等于现场听感验收，最终仍需在实际屏幕扬声器试听。

| ID | 文案 | 触发 |
| --- | --- | --- |
| 1 | 请问，这是什么垃圾？ | 新题 |
| 2 | 答对了！ | 首次答对 |
| 3 | 再想一想。 | 错误反馈之一 |
| 4–7 | 这是厨余垃圾／有害垃圾／其他垃圾／可回收垃圾。 | 答题后的正确类别后缀 |
| 8 | 恭喜你，又答对了！ | 连续第二次 |
| 9 | 你已经连续三次答对了，非常棒！ | 连续第三次 |
| 10 | 环保小能手，继续加油！ | 后续连续答对轮换 |
| 11 | 太棒了，判断很准确！ | 后续连续答对轮换 |
| 12 | 别灰心，下一次一定可以。 | 错误反馈轮换 |
| 13 | 差一点点，记住这个答案。 | 错误反馈轮换 |
| 14 | 当前是跑分页面，请按按键一开始跑分。 | 进入跑分页 |

ID8–13是新增六条答题反馈。页面播报不附加垃圾类别后缀；离开页面会中断页面提示。题目播报和跑分播报由`trash_voice_i2s.v`路由，运行时不读取下面旧版WAV清单。

## 历史离线WAV生成入口

语音由 `application/tools/make_voice.ps1` 使用本机 `Microsoft Huihui Desktop` 离线生成，输出格式统一为 48 kHz、16-bit、单声道 PCM WAV。文本中的“哎呀，答错了”是对“哎呀打错了”的语义规范化。

| 文件 | 播放文案 | 用途 |
| --- | --- | --- |
| `PROMPT.WAV` | 请选择垃圾桶。 | 检测到目标后提示选择 |
| `CORRECT.WAV` | 恭喜你，答对了！ | 答题正确 |
| `WRONG.WAV` | 哎呀，答错了。 | 答题错误 |
| `TIMEOUT.WAV` | 选择超时，请移走垃圾后重试。 | 等待答题超时 |

生成后的 WAV 会写入 `application/assets/audio/`，上板时复制到 FAT32 SD 卡根目录。`VOICE_MANIFEST.json` 保存文案和格式元数据；该 JSON 不会被音频播放固件加载。
