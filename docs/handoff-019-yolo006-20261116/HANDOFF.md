## 移机使用与继续训练

1. 解压01代码包后，在其根目录运行`python tools/check_package.py`和`python tools/check_current_019.py`。
2. 解压03训练数据包，按其中README安装Python3.12/GPU环境，运行`python configure_training.py`重建路径。训练入口使用NVIDIA GPU0，字体依赖Windows Arial；环境安装包/驱动/PDS/许可证不在本总包中。
3. 从006继续训练时，将02中的best.pt复制为数据包根目录的`candidate_006.pt`，在数据包根目录运行：

```powershell
python train_gpu.py --yolo upstream/yolov5-7.0 --data configured/data.yaml --weights candidate_006.pt --project runs --name personal_next_001 --epochs 24 --batch 32 --imgsz 320 --freeze 2 --freeze-bn --lr0 0.0001 --threads 4
```

这是可复现的起始命令，不意味着建议不改数据直接重复训练。name必须为新目录。

自采纸张目前只在val，不要搬入train。优先审查空手15张误选、漏检手和纸团错误，再补板载摄像头不同实物/人物/光照的数据；保留独立新场景测试。改模型或策略时分别统计电池、手部、可回收、空手和公共类回退，避免只看总mAP。

新模型部署顺序：浮点评估→导出与量化→实际C运行时数值核对→更新绑定模型长度/CRC的固件→完整FPGA时序/资源核查→实际板测→更新Flash/TF配套文件。详细重建命令见06中的代码交接文档。
