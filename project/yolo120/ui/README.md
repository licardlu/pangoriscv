# YOLO120 显示与外设资源

`rtl/light_split_video.sv` 把 YOLO 后的 1280×720 RGB565 视频与白色控制面板合成为一帧，右侧保留摄像头画面，左侧显示状态、分数和音频状态。背景、状态条、调色板和语音素材均放在本目录，便于随主工程提交和复现仿真。

`project/yolo120/rtl/servo_pwm4.sv` 是四路 50 Hz PWM。触发某一路后输出 1.5 ms（约 90°）保持 5 秒，再回到 0.5 ms（约 0°）。四路顺序固定为蓝色可回收、灰色其他、红色有害、绿色厨余。实际 FPGA 引脚仍需在板卡约束中确认后才能下载验证。
